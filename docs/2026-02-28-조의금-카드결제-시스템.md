# 조의금(부의금) 카드결제 시스템

> 최종 업데이트: 2026-02-28

## 📋 개요

조문객이 부고 페이지에서 상주를 선택하여 카드결제로 부의금을 보내면, 서버에서 자동으로 상주 계좌로 송금하는 시스템.

## 🔄 전체 플로우

```
조문객 (클라이언트)
  ↓ 카드결제 버튼 클릭
  ↓ /view/{bugo_number}/condolence?m={상주인덱스}
  ↓ 금액 선택 + 이름/연락처 입력
  ↓ InnoPay SDK (innopay.goPay)
  ↓
InnoPay 결제창 (PG사)
  ↓ 결제 승인
  ↓ returnUrl → /view/{id}/payment/callback
  ↓
콜백 페이지 (클라이언트)
  ↓ POST /api/payment/innopay/approve
  ↓
승인 API (서버) ← approve/route.ts
  ├─ InnoPay 승인 API 호출 (api.innopay.co.kr)
  ├─ condolence_orders DB 저장
  ├─ 슬랙 알림 발송
  ├─ 조문객 알림톡 발송 (결제완료)
  ├─ 프록시 서버(49.50.139.204)로 송금 요청
  │     ↓ 송금 성공 시
  │     ├─ DB status → 'transferred'
  │     └─ 상주 알림톡 발송 (입금 알림)
  └─ 리다이렉트 → /order/{orderNumber}
```

## 📁 파일 구조

### 클라이언트 (프론트엔드)

| 파일 | 역할 |
|------|------|
| `app/view/[id]/ViewContent.tsx` | 부고 페이지 - 계좌별 "카드결제" 버튼 (localhost에서만 표시) |
| `app/view/[id]/condolence/page.tsx` | 카드결제 페이지 서버 컴포넌트 (DB에서 상주 계좌 정보 조회) |
| `app/view/[id]/condolence/CondolenceContent.tsx` | 카드결제 UI (결제정보 입력 + InnoPay SDK) |
| `app/view/[id]/condolence/condolence.css` | 카드결제 페이지 스타일 |
| `app/view/[id]/payment/callback/page.tsx` | InnoPay 결제 후 콜백 (승인 요청) |
| `app/view/[id]/condolence/complete/page.tsx` | 결제완료 → /order 페이지로 서버사이드 리다이렉트 |

### 서버 (API)

| 파일 | 역할 |
|------|------|

### 수수료 구조
- 부의금 = 면세 상품 (`taxFreeAmt`로 처리)
- `amt`(과세) + `taxFreeAmt`(면세) = 총 결제금액
- `fee = totalAmount - selectedAmount`
