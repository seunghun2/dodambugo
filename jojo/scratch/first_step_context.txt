53: ## 2. 텍스트 방향 (Text Orientation)
54: 
55: ### SVG에서의 방향:
56: - **위패/지방**: 모두 **세로 쓰기** (vertical top-to-bottom) — SVG에서 `<tspan x="0" y="0">顯</tspan><tspan x="0" y="49.944">叔</tspan>...` 패턴으로 각 글자를 y 좌표로 아래로 배치
57:   - CSS `writing-mode: vertical-rl` 사용이 아니라, **각 글자를 개별 y 좌표로 배치**하는 방식
58:   - 즉, x 값은 고정이고 y 값만 증가하는 단일 세로 컬럼
59: - **축문**: **가로 쓰기** (horizontal left-to-right) — 일반/불교 축문은 전통 한문으로 가로 배치, 기독교/천주교는 한글 가로 쓰기
60: - **기도 문구 (기독교/천주교)**: 세로 쓰기 — 예: "주님", "그에게", "영원한", "안식을", "주소서" 와 "영원한", "빛을", "그에게", "비추소서" 가 **세로로 각 글자 한 칸씩** 배치
61: 
62: ### 현재 구현의 방향:
63: - **지방/위패**: flexbox column + `div` 개별 글자 방식 (SVG 방식과 동일한 시각적 결과)
64: - **축문**: 가로 쓰기 (SVG와 동일)
65: - **기도 문구**: 세로 쓰기 (flexbox column으로 구현) — ✅ 이미 올바르게 구현됨
