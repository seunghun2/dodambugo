## 1. SVG에 있지만 현재 구현에 없는 기능/요소

### (A) **명패 (Name Plate) — 울산/포항 전문장례식장 SVG**
- `울산전문장례식장 위패 - 명패.svg` 와 `포항국화원 위패 - 명패.svg` 에는 **"명패"** 와 **"위패"** 두 가지 별도 디자인이 있음
- 명패 = 한글 이름을 세로로 크게 표시 (예: "홍 길 동"), 아래에 "고 인" 텍스트
- **현재 구현**: 명패(한글 이름만 표시하는 단순 형태)는 지원하지 않음. 위패만 한자 중심으로 생성됨.

### (B) **혼백 (혼백 확인) 탭 — 기독교/천주교 SVG #2**
- `01_01_04_01이용신청서(위패축문확인-기독교,천주교) – 2.svg`에는 탭이 **"위패 확인"** 과 **"혼백 확인"** 두 개 존재
- 혼백: 기독교/천주교 특유의 기도 문구가 포함된 위패 변형 형태
- **현재 구현**: 혼백 탭은 `jibangSize` 옵션에서 "혼백·명패 크기 (4.4 x 26.6cm)"로 **사이즈만** 제공되지만, 별도 "혼백 확인" UI 탭이나 고유 레이아웃은 없음

### (C) **축문 카테고리 분리: "기제사 축문" vs "장례지도사용 축문"**
- SVG의 축문 확인 화면에서는 두 개의 탭 버튼이 존재:
  - **"기제사 축문"** (파란색 활성 탭)
  - **"장례지도사용 축문"** (비활성 탭)
- **현재 구현**: 축문 종류가 하나의 `<select>` 드롭다운으로 통합되어 있음 (기제사/설날/추석/장례(발인제)/초혼 등). 탭 기반 분리 아님.

### (D) **"초혼 (招魂)" 설명 텍스트**
- SVG에 "- 고인의 혼을 부르는 의식" 이라는 파란색 설명 텍스트가 초혼 옆에 표시됨
- **현재 구현**: 초혼이 `<select>` 드롭다운 항목에 포함되어 있지만, 부가 설명 텍스트는 없음

### (E) **무늬 (Pattern/Decoration) 선택 필드**
- SVG 파일들(일반/불교, 기독교/천주교 모두)에 **"무늬"** 라벨과 **"없음"** 텍스트가 있음
  - 이는 위패 배경/테두리 무늬(패턴)을 선택하는 옵션
- **현재 구현**: 무늬 선택 UI가 전혀 없음. 모든 위패/지방은 단일 이중 선 프레임(border)만 사용

### (F) **다중 축문 사이즈/디자인 변형**
- `(00)예시_위패사이즈 및 디자인변경.svg`에는 SVG 기반 장식 패턴이 테두리에 적용된 위패 디자인이 있음:
  - 반복되는 연꽃/화문 패턴이 좌우 세로 테두리에 배치됨 (`반복 그리드 342`)
  - 상하에도 동일 패턴이 가로로 적용됨
- `(00)예시_위패사이즈 및 디자인 – 1.svg`는 **6개 이상의 위패 변형**을 한 페이지에 배치:
  - 다양한 종교 심볼(십자가, 이중십자가, 만(卍)자 등), 각각 다른 레이아웃
- **현재 구현**: 단일 이중 선 프레임만 지원. 장식 패턴/피부 선택 불가.

### (G) **B2B 이용신청서 풀 워크플로우 (4단계)**
- `01_01_04_02이용신청서(위패축문확인-기독교,천주교).svg`에는 B2B 관리 시스템 전체 UI가 표시됨:
  - 좌측 메뉴: 장례식 관리, 실시간 빈소현황, 퇴실자 관리, 이용신청서 작성, 업무서식 출력, 현황판 설정
  - 상단 메뉴: 장례식장 관리, 운영관리, 마케팅관리, 뉴스, 장례 데이터, 고객센터, POS
  - 4단계 진행 표시: "1. 입실 기본정보 → 2. 시설 및 서비스 선택 → 3. 음식 주문 → **4. 위패/축문 확인**"
  - 완료 상태 배지, 임시저장 날짜, "저장 후 나가기" 버튼
- **현재 구현**: 이런 전체 관리 시스템 UI는 범위 밖. 현재 ritual 페이지는 독립 페이지로 동작.

## 2. 텍스트 방향 (Text Orientation)

### SVG에서의 방향:
- **위패/지방**: 모두 **세로 쓰기** (vertical top-to-bottom) — SVG에서 `<tspan x="0" y="0">顯</tspan><tspan x="0" y="49.944">叔</tspan>...` 패턴으로 각 글자를 y 좌표로 아래로 배치
  - CSS `writing-mode: vertical-rl` 사용이 아니라, **각 글자를 개별 y 좌표로 배치**하는 방식
  - 즉, x 값은 고정이고 y 값만 증가하는 단일 세로 컬럼
- **축문**: **가로 쓰기** (horizontal left-to-right) — 일반/불교 축문은 전통 한문으로 가로 배치, 기독교/천주교는 한글 가로 쓰기
- **기도 문구 (기독교/천주교)**: 세로 쓰기 — 예: "주님", "그에게", "영원한", "안식을", "주소서" 와 "영원한", "빛을", "그에게", "비추소서" 가 **세로로 각 글자 한 칸씩** 배치

### 현재 구현의 방향:
- **지방/위패**: flexbox column + `div` 개별 글자 방식 (SVG 방식과 동일한 시각적 결과)
- **축문**: 가로 쓰기 (SVG와 동일)
- **기도 문구**: 세로 쓰기 (flexbox column으로 구현) — ✅ 이미 올바르게 구현됨

## 4. 장식/테두리/스킨 비교

### SVG 디자인들:
1. **기본 이중 프레임**: 외곽선 1px + 내부 4px 간격 + 내부선 (`아트보드 – 1.svg` 등) — ✅ **현재 구현과 동일**
2. **연꽃/화문 장식 패턴 테두리** (`(00)예시_위패사이즈 및 디자인변경.svg`): 반복 패턴이 테두리를 장식 — ❌ **미구현**
3. **종교별 다양한 심볼 위치**:
   - 십자가(빨간색 #de0615): ✅ 구현됨
   - 이중 십자가(천주교): ✅ 구현됨  
   - 불교 만(卍)자 + 연꽃 (#c94251, 원 #eaad2d): ✅ 구현됨
   - 일반(유교) 심볼: SVG에 없음 = 현재도 없음 ✅
4. **사각 코너 장식** (`아트보드 – 1.svg`): 네 코너에 작은 사각형(■)+십자 패턴이 있는 상세 테두리 — ❌ **미구현**
5. **반원 패턴 테두리** (`아트보드 – 1.svg` 우측 위패): 좌우 테두리에 반원이 연속 배열된 전통 장식 — ❌ **미구현**

## 5. 위패 레이아웃 패턴 요약

### SVG에서 발견된 레이아웃 패턴:

**패턴 A — 기본 (일반/불교/기독교/천주교 공통)**:
- 이중 직사각형 프레임 안에 세로 한 칼럼
- 87mm × 248mm (레퍼런스 사이즈)
- 글자: 顯→叔→父→學→生→府→君→神→位 (9줄, 세로)
- 종교 심볼이 글자 위에 배치

**패턴 B — 명패 (한글 전용)**:
- 이중 프레임 + 내부 단일 프레임
- 한글 이름 세로 배치 (홍→길→동) + 하단에 "고 인" 표시
- 87mm × 248mm

**패턴 C — 기독교/천주교 확장**:
- 기본 패턴에 좌측 기도문구 세로 컬럼 추가
- 2컬럼 레이아웃: [기도문구 | 위패 본체]

**패턴 D — 장식 테두리 위패**:
- 반복 패턴(연꽃) 테두리로 둘러싸인 위패

**패턴 E — 다중 위패 배치 (인쇄용)**:
- A4 페이지에 3~4개 위패를 나란히 배치하는 레이아웃

### 현재 구현 상태:
- ✅ 패턴 A: 완전 구현됨
- ❌ 패턴 B (명패): 미구현
- ✅ 패턴 C: 기도문구 칼럼 구현됨
- ❌ 패턴 D: 장식 테두리 미구현
- ❌ 패턴 E: 다중 배치 미구현
