Service Overview

서비스 개요

모바일 부고장 내 카드결제를 통한 부의금 즉시 전달 서비스

서비스 정의

조문객이 모바일 부고장에서 신용카드 및 간편결제로 부의금을 결제하면, 상주의 개인 계좌로 즉시 입금(1~3분)되는 B2B 솔루션입니다.

User Flow — Sender

조문객 이용 플로우

부의금 확인부터 결제 완료까지 약 30초

1

부의금 확인 · 카드결제 클릭

모바일 부고장에서 부의금 계좌 확인 후, 하단의 "카드결제" 버튼을 클릭합니다.

화면 요소

계좌 정보 · 카드결제 버튼

2

정보 입력 · 금액 선택

보내시는 분의 성함·연락처를 입력하고, 6가지 금액 중 원하는 금액을 선택합니다.

금액 옵션

5만 · 10만 · 20만 · 30만 · 50만 · 100만원

결제 완료

결제 수단을 선택하고 결제를 완료합니다. 결제 전 주의사항을 확인합니다.

주의사항

부의금은 상주 계좌로 즉시 입금되어 환불 불가 재차 공지

전체 소요 시간: 약 30초 · 앱 설치 불필요 · 회원가입 불필요

User Flow — Receiver

상주 이용 플로우

결제 접수부터 부의금 수령까지 자동화된 프로세스

실시간 알림 프로세스

1

조문객 결제 접수

PG사에서 결제 승인이 완료되면 플랫폼에 웹훅(Webhook)으로 통보됩니다.

2

상주 계좌 즉시 입금

예치금에서 부의금 전액을 차감하여 상주 계좌로 1~3분 내 자동 송금합니다.

3

알림톡 즉시 발송(알림톡 설정 필요)

상주에게 카카오 알림톡으로 "OOO님이 부의금 OO만원을 보냈습니다" 안내가 발송됩니다.

4

부의금 내역 자동 기록

보낸 분 성함, 금액, 시간이 자동 저장되어 상주가 언제든 조회할 수 있습니다.

상주 관리 기능

부의금 수령 내역 조회

모바일 부고장 내 "조의금 내역" 페이지에서 실시간 확인 가능

엑셀 다운로드

전체 부의금 내역을 엑셀 파일로 다운로드하여 정리 가능

본인 인증

상주 본인만 내역을 조회할 수 있도록 휴대폰 뒷자리 인증 적용

Payment System

결제 시스템 상세

PG 연동 구조 및 가맹점 운영 방식

가맹점 이중 구조

MID #1 — 결제용

조문객의 카드결제를 처리합니다. 결제 승인 후 PG사가 D+5일에 정산합니다.

MID #2 — 예치금용

플랫폼 예치금을 보유하며, 결제 확인 즉시 상주 계좌로 펌뱅킹 송금합니다.

결제 자금과 송금 자금이 분리되어 자금 흐름의 투명성과 안전성을 보장합니다.
