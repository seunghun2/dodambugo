## 📑 2. E2E 실전 검수 시나리오 단계별 마일스톤

### 📍 [1단계] 회원가입 & 추천 코드 연동 검수
- [ ] **백승훈 ➡️ 김미연 추천 링크 전송**: 백승훈 파트너의 4자리 추천코드 공유 링크 발송
- [ ] **김미연 회원가입 5단계 진행**: 쿼리 파라미터(`?ref=XXXX`)로 추천인 백승훈 성명/상호 자동 대입 확인
- [ ] **가입 완료 실시간 알림 검수**:
  - [ ] **B2B 전용 슬랙 채널**로 신규 회원가입 통지 메시지 수신 확인
  - [ ] 백승훈 파트너 휴대폰으로 **추천 알림톡/SMS 및 인앱 알림** 수신 확인

---

### 📍 [2단계] 모바일 부고장 생성 및 공유 검수
- [ ] **김미연 파트너의 모바일 부고장 1건 작성**: 고인, 빈소, 발인일, 상주 정보 입력
- [ ] **부고장 링크 카카오톡 / SMS 공유**: 공유 도메인이 `bugoon.maeumbugo.co.kr/view/{id}`로 정확히 나가는지 확인
- [ ] **부고장 미리보기 바텀시트**: 94vh 슬라이드업 미리보기 모달 정상 작동 확인

---

### 📍 [3단계] 조문객 실결제 (화환 & 부의금 이노페이 PG) 검수
- [ ] **조문객 화환 결제 시도**: 부고장에서 화환 1건 실결제 진행
- [ ] **조문객 부의금 결제 시도**: 부고장에서 부의금 1건 실결제 진행
- [ ] **실시간 결제 통지 검수**:
  - [ ] **B2B 슬랙 채널**로 `[부고온] 화환 주문 접수` 및 `[부고온] 부의금 전달` 실시간 알림 수신
  - [ ] 백승훈 대표님 스마트폰 푸시 알림 수신
  - [ ] 부의금은 상주 계좌로 자동 입금/송금 완료 확인
  - [ ] 화환 주문은 어드민 화환 발주 목록에 정식 적재 확인

---

### 📍 [4단계] 화환 발주 & 알림톡 템플릿 검수
- [ ] **어드민 화환 배송 상태 변경**: 어드민에서 배송 상태를 `배송 중(delivering)` ➡️ `배송 완료(delivered)`로 변경
- [ ] **조문객용 알림톡 검수**:
  - [ ] **배송 출발 알림톡**: '05-화환 배송 출발/안내' 올바른 템플릿 및 상품명/장례식장/고인명 수신 확인 (부의금 템플릿 오발송 0건)
  - [ ] **배송 완료 알림톡**: '06-화환 배송 완료' 올바른 템플릿 수신 확인
- [ ] **파트너 지도사용 LMS/인앱 알림 검수**:
  - [ ] 김미연 지도사 휴대폰으로 `[부고온] 파트너 화환 배송 완료` LMS 및 인앱 알림 수신 확인

---

### 📍 [5단계] 수당 정산 분배 실시간 대조 QA (핵심!)

#### 🅰️ 김미연 (개인 지도사) 부고장 화환 결제 결과 대조
- [ ] **김미연 지갑**: 화환 판매 수당 **`+20,000원`** 즉시 적립 확인
- [ ] **백승훈 지갑**: 추천 파트너 보너스 **`+2,500원`** 즉시 적립 확인
- [ ] **알림 통지**: 김미연(수당 적립 알림) & 백승훈(추천 보너스 적립 알림) 수신 확인

#### 🅱️ 홍길동 (상조소속 지도사) 부고장 화환 결제 결과 대조
- [ ] **홍길동 지갑**: 소속 지도사 수당 **`+20,000원`** 즉시 적립 확인
- [ ] **상조 본사 장부**: 상조 본사 정산금 **`+20,000원`** (`pending` 상태) 적립 확인
- [ ] **백승훈 지갑**: 상조 소속 계정이므로 추천 보너스 **중복 지급 미발생(0원)** 검증 통과

---

### 📍 [6단계] D+1 정산 이체 & 수당 환급 출금 및 어드민 견적서 적재 QA
- [ ] **지도사 수당 환급 출금 신청**: 김미연 지갑에서 15,000원 환급 신청 (3.3% 원천세 공제 사전 고지 확인)
- [ ] **어드민 출금 승인 및 실이체**: 어드민 `/b2b/admin/withdrawals` 에서 승인 ➡️ 이노페이 펌뱅킹으로 김미연 계좌 입금 완료
- [ ] **환급 완료 알림톡**: 지도사 휴대폰으로 환급 완료 알림톡 수신 확인
- [ ] **어드민 정산서/견적서 연동 확인**: 어드민 장부 및 견적서 항목에 해당 20,000원 수당 정산 내역이 정확한 항목명과 금액으로 적재되는지 최종 검증

## 🛠️ 3. 에이전트(AI)의 실시간 밀착 QA 모니터링 역할

대표님께서 각 시나리오 단계를 한 걸음씩 실행하실 때마다, 저는 다음을 수행합니다:
1. **DB 실시간 트레이스**: 수당 테이블(`deposits`, `deposit_transactions`, `b2b_company_settlements`) 데이터 1원 단위 대조
2. **로그 수색**: Solapi 알림톡 발송 결과 코드(`2000`), 이노페이 PG 승인 응답 코드 감시
3. **오류 즉시 리포트 & 원포인트 수정**: 유저 경험 중 발생하는 아주 미세한 오타, 레이아웃 깨짐, 알림 지연을 즉시 원인 분석하여 실시간 정정 코드 적용!
