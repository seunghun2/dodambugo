* **실행 동작**: 김미연 휴대폰으로 공유 링크 진입 ➡️ 5단계 가입 폼 작성 (상호명 '개인', 이름 '김미연', 휴대폰, 비밀번호, 계좌) ➡️ 가입 완료.
* **기술 검증 항목**:
  - [ ] URL 파라미터 `?ref=1234`를 인식하여 추천인 입력란에 '1234'가 자동 대입되고 상단에 `[추천인: 백승훈 (개인 장례지도사)]` 안내가 뜨는가?
  - [ ] 휴대폰 번호 중복 체크 API `/api/b2b/signup` (checkOnly 모드)가 정상 동작하는가?

  - [ ] 비밀번호가 bcrypt 해시 처리되어 평문 노출이 없는가?

### 1-3. 가입 완료 직후 알림 통합 수신 검증

  - [ ] **백승훈 파트너 휴대폰**: 카카오 알림톡/LMS로 `[부고온] 파트너 가입 알림 (김미연 파트너님이 회원님을 추천하여 가입했습니다)` 수신 확인.

  - [ ] **백승훈 지갑(`deposits`)**: 추천 파트너 화환 판매 보너스 **`+2,500원`** 이 백승훈 지갑 잔액에 즉시 반영되는가?
  - [ ] **수당 적립 알림**: 김미연(화환 수당 20,000원 적립 알림) 및 백승훈(추천 보너스 2,500원 적립 알림)에게 인앱/푸시/알림톡 수신 확인.
