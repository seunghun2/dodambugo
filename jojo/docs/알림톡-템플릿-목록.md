## 📱 B2B 부고온 알림톡 템플릿 목록

### B2B-1. 부고장 생성 완료 (상주용)
- **발송 시점:** 부고온 파트너 앱/웹에서 부고장 생성 완료 시
- **수신자:** 상주
- **카테고리:** 처리완료 (004003)
- **변수:** 고인명, 장례식장, 발인일시, 부고번호, owner_token
- **알림톡 본문 내용:**
  ```
  상주님, 요청하신 부고장 생성이 완료되었습니다.

  - 고인: #{고인명}님
  - 장례식장: #{장례식장}
  - 발인일시: #{발인일시}

  아래 버튼을 눌러 부고장을 확인하고 지인분들께 안내해 주세요.
  ```
- **버튼:** `부고장 확인하기` (웹링크 WL)
  - 링크 주소: `https://bugoon.maeumbugo.co.kr/view/#{부고번호}?token=#{owner_token}`
- **대체발송 문자 내용 (버튼이 없으므로 링크 직접 기재):**
  ```
  상주님, 요청하신 부고장 생성이 완료되었습니다.

  - 고인: #{고인명}님
  - 장례식장: #{장례식장}
  - 발인일시: #{발인일시}

  아래 링크를 눌러 부고장을 확인하고 지인분들께 안내해 주세요.
  https://bugoon.maeumbugo.co.kr/view/#{부고번호}?token=#{owner_token}
  ```
