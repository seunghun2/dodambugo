## 🕐 CTA 노출 타임라인

```
Day 0~2   → 일반 부고장 (오버레이 없음)
Day 3~7   → 오버레이 + [부의금 전하기] + [장지 비교하기]
Day 8~29  → 오버레이 + [장지 비교하기] only
Day 30+   → 열람 기간 종료 (비공개 처리)
```

- `isFuneralEnded()`: 발인일 +3일 후 오버레이 표시
- `showCondolenceCTA`: `getDaysSinceFuneral() <= 7` (발인 후 7일까지만 부의금 노출)
- `isExpired()`: 발인일 +30일 후 페이지 비공개
