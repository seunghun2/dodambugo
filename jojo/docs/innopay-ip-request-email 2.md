# Innopay IP 등록 요청 메일 (초안)

---

**제목**: 펌뱅킹 송금 API IP 등록 요청 (대대손손/도담부고)

---

안녕하세요, 이노페이 담당자님.

대대손손(도담부고) 서비스를 운영하고 있는 백승훈입니다.

펌뱅킹 송금 API 연동 관련하여, API 호출에 사용할 **고정 IP 등록을 요청**드립니다.

### 요청 사항
- **서비스명**: 대대손손 (도담부고)
- **가맹점 ID**: (가맹점 ID 입력)
- **등록 요청 IP**: `[공인 IP 입력]`
- **용도**: 부의금 온라인 결제 후 상주 계좌로 자동 송금 (펌뱅킹)

### 배경
현재 서비스는 Vercel 클라우드에서 운영 중이며, Vercel 특성상 고정 IP 할당이 불가합니다.
이에 네이버 클라우드 플랫폼(NCP)에 프록시 서버를 구축하여 고정 IP를 확보하였습니다.
해당 프록시 서버를 통해 펌뱅킹 API를 호출할 예정이오니, 위 IP를 화이트리스트에 등록 부탁드립니다.

### 확인 부탁드리는 사항
1. 위 IP 등록 처리 가능 여부
2. 등록 완료 예상 시간
3. 추가로 필요한 서류나 정보가 있는지

감사합니다.
빠른 확인 부탁드립니다.

백승훈 드림
대대손손 / 도담부고
연락처: (전화번호 입력)
이메일: (이메일 입력)

---

> ⚠️ 서버 생성 완료 후 `[공인 IP 입력]` 부분에 실제 IP 넣고 보내기!
