1. 서비스 개요 및 비즈니스 모델

1) 서비스 정의

  • 부의금 카드결제 서비스는 모바일 부고장 내에서 조문객이 카드로 부의금을 결제할 수 있도록 하는 서비스
  • 기존 부의금 전달 방식은 현금 또는 계좌이체로 한정되어 있으며, 이로 인해 다음과 같은 문제가 발생함
    • 현금을 미리 준비해야 하는 번거로움
    • 직접 조문이 어려운 경우 부의금 전달 자체가 불가능
    • 계좌이체 시 상주 입장에서 부의금 내역 관리의 어려움
  • 따라서, 모바일 부고장과 카드결제를 결합하여 조문객은 간편하게, 상주는 자동으로 내역을 관리할 수 있는 구조를 설계해야 함
항목 내용
서비스명 부의금 카드결제
서비스 제공자 마음부고 (모바일 부고장 플랫폼)
주요 사용자 조문객 (결제자) / 상주 (수취인)
결제 수단 신용카드, 카카오페이, 네이버페이, 토스페이
수수료 8.6%(예상) (조문객 부담, 상주 0원)
핵심 가치 원거리 조문 지원, 부의금 내역 자동 기록, 즉시 송금

2) 비즈니스 모델

  • 본 서비스는 거래 수수료 기반의 수익 모델을 채택함
  • 조문객이 부의금을 카드로 결제할 때 발생하는 수수료(8.6%)가 최적의 수수료라고 판단하고 있으며, 이 수수료는 전액 조문객이 부담함
    • 상주에게는 수수료 없이 결제 금액 전액이 즉시 송금됨
  • 매출은 부고장 발행 → 카드결제 발생 시점에서만 발생하며, 부고장 발행 자체는 무료로 제공함
  • 따라서, 수익 극대화를 위해서는 ① 제휴처(모바일 부고장 업체) 수 확대, ② 부고장당 카드결제 전환율 제고가 핵심 과제가 됨
흐름 ① 부고장 발행 ② 부고장 열람 ③ 카드결제
활동 상주가 모바일 부고장 생성 조문객이 링크를 통해 열람 부의금을 카드로 결제
매출 발생 없음 (무료) 없음 수수료 8.6% 발생
활동 주체 부고장을 제작하는 이 조문객 조문객

3) 수익구조

  • 조문객이 부담하는 총 수수료 8.6%는 다음과 같이 분배됨
항목 비율 설명
PG 수수료 3.2% PG사(결제대행사)에 지급하는 카드 결제 처리 수수료
제휴처 수수료 (마음부고) 0.2% 마음부고에 지급하는 서비스 제공 대가
플랫폼 수수료 (거래처) 5.2% 거래처(모바일 부고장 업체)의 순수익
합계 8.6% 조문객 부담 총 수수료
* 부가서비스: 송금대행 수수료 건당 300원 별도 (상주 계좌로 즉시 송금 시 발생)
  • 플랫폼 수수료 5.2%는 거래처(모바일 부고장 업체)의 핵심 수익원임
  • 마음부고의 수익은 제휴처 수수료 0.2%이며, 결제 건수가 늘어날수록 수익이 비례하여 증가하는 구조임

2. 서비스 설계

1) 사용자 플로우 (조문객)

  • 조문객의 결제 플로우는 3단계로 구성되며, 전체 소요 시간은 약 30초 이내로 설계됨
  • 앱 설치 및 회원가입 불필요 → 모바일 웹 기반으로 접근성을 극대화함
단계 화면 사용자 행동 시스템 처리
1단계 부의금 계좌 모달 부고장 열람 → 부의금 계좌 확인 → "카드결제" 버튼 클릭 결제 페이지로 이동
2단계 카드결제 페이지 보내시는 분 성함·연락처 입력, 금액 선택 (5만~100만원) 주문 정보 생성
3단계 결제 확인 · 완료 주의사항 확인(환불불가) → 결제수단 선택 → 결제 PG 결제 처리 → 상주 계좌 즉시 송금 → 알림톡 발송
  • 금액 옵션은 5만 · 10만 · 20만 · 30만 · 50만 · 100만원의 6가지로 고정 제공
    • 부의금 관례상 통용되는 금액대를 기준으로 설정
    • 직접 입력 방식 대비 선택형이 결제 전환율이 높은 것으로 판단
  • 결제 전 "부의금은 상주 계좌로 즉시 입금되어 환불이 불가합니다" 주의사항을 재차 공지하여 분쟁을 사전 방지함

2) 상주 관리 기능

  • 상주(유족)는 별도의 관리 페이지를 통해 부의금 내역을 실시간으로 확인할 수 있음
  • 관리 기능은 어드민 페이지를 통해 제공되며, 핵심 기능은 다음과 같음
기능 설명
부의금 내역 조회 보낸 분 성함, 금액, 결제 시간을 실시간 확인
엑셀 다운로드 전체 부의금 내역을 엑셀 파일로 다운로드
알림톡 수신 부의금 결제 완료 시 상주에게 알림톡 즉시 발송 (알림톡 설정 필요)
개인정보 보호 휴대폰 번호 뒷 4자리 인증을 통한 내역 접근 제한

3) 결제 시스템 구성

  • 결제 처리는 PG사를 통해 이루어지며, 전체 시스템은 다음과 같이 구성됨
구성 요소 역할 비고
조문객 (웹) 결제 요청 모바일 웹 기반, 앱 불필요
PG사 카드 결제 승인 및 정산 3.2% + @ 수수료 처리
펌뱅킹 상주 계좌로 즉시 송금 건당 300원 (부가서비스)
상주 부의금 수령 수수료 부담 없음 (0원)
  • 결제 → 송금이 실시간(즉시)으로 이루어지는 구조이므로, 상주 입장에서는 계좌이체와 동일한 경험을 제공받게 됨
  • 이 즉시 송금 구조가 환불 불가 정책의 근거가 되며, 결제 전 주의사항으로 충분히 고지함

4) 정산 구조

  • 정산은 다음과 같은 흐름으로 처리됨
단계 처리 내용 시점
1. 결제 조문객이 부의금 + 수수료(8.6%) 결제 즉시
2. 송금 부의금 원금을 상주 계좌로 즉시 송금 결제 후 즉시
3. PG 정산 PG사에서 결제 대금(수수료 포함)을 거래처 계좌로 정산 D+5 영업일
4. 수수료 분배 플랫폼 수익 확정 후 PG사에서 마음부고로 수수료 지급 PG 정산 후
* 즉시 송금은 거래처의 가상계좌 예치금에서 선지급하는 구조이므로, 충분한 예치금 확보가 운영상 필수 요건임

3. 운영 정책

1) 결제 한도

구분 한도 비고
1회 최소 결제 50,000원 부의금 관례상 최소 금액
1회 최대 결제 1,000,000원 이상거래 방지 목적
1일 최대 한도 1,000,000원 동일인 기준

2) 환불 정책

  • 부의금은 결제 즉시 상주 계좌로 송금되므로, 원칙적으로 환불이 불가함
  • 결제 전 주의사항 팝업을 통해 "부의금 결제는 상주님의 계좌로 즉시 입금되어 환불이 불가합니다"를 고지하고, 사용자의 동의를 받은 후 결제가 진행됨
  • 예외적 환불 사유는 다음과 같음
사유 처리 방법 비고
결제 후 클레임 PG 취소를 통한 전액 환불 가능 극히 드문 케이스
송금 완료 후 상주-조문객 간 직접 협의 플랫폼 개입 불가

3) 이상거래 방지

  • 부의금 카드결제의 특성상 이상거래(자금세탁, 허위 결제 등) 방지가 중요하며, 다음과 같은 조치를 적용함
조치 내용
결제 한도 설정 1회/1일 한도를 통해 대량 결제를 사전 차단
중복 결제 방지 동일인 동일 부고장에 대한 단시간 내 반복 결제 제한
실명 확인 결제 시 성함·연락처 수집을 통한 결제자 식별
모니터링 비정상 패턴(단시간 다건 결제, 고액 집중 등) 자동 감지

4. 수익 시뮬레이션 및 성장 전략

0) 기존 거래 실적 기반 역산

  • 기존 거래처 1곳의 실제 운영 실적을 기반으로 역산하여 시뮬레이션의 기초 데이터로 활용함
항목 값 산출 근거
월 부고장 발행 건수 3,000건 거래처 1곳 기준 실적
월 카드결제 건수 2,200건 월 GMV ÷ 건당 평균 부의금
건당 평균 부의금 100,000원 부의금 관례상 10만원이 가장 보편적
월 총 거래액 (GMV) 220,000,000원 거래처 1곳 실측 데이터 (2.2억원/월)

* 부고장 3,000건 중 카드결제가 발생하는 비율은 약 73%이며, 카드결제 전환율 향상을 통해 추가 성장 여지가 있음을 의미함

  • 기존 거래 실적(월 GMV 2.2억원)을 역계산하여, 거래액 조의금 10억원을 통한 매출 시나리오를 산출함

월 수익 (0.2%)		 마음부고
연 수익		 거래처
월 수익 (5.2%)
목표 10억원 10,000건 2,000,000원 24,000,000원 52,000,000원
  • 거래처 1곳이 월 GMV 10억원 달성 시, 마음부고 월 200만원(연 2,400만원)의 수익을 기대할 수 있음
  • 거래처 입장에서는 월 5,200만원(연 6.24억원)의 추가 수익이 발생하므로, 서비스 도입의 강력한 유인이 됨

3) 추가 성장 레버

  • 현재 부고장당 평균 결제 건수가 0.73건으로, 카드결제 전환율 향상이 추가 성장의 핵심임
    • 전환율 1.0건 달성 시: 거래처 1곳 월 GMV 2.2억 → 3.0억 (36% 성장)
    • 전환율 1.5건 달성 시: 거래처 1곳 월 GMV 2.2억 → 4.5억 (105% 성장)
  • 건당 평균 부의금 상승 또한 GMV 증가에 직접 기여함
